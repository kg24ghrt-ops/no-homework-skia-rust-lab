# No Homework Skia Rust Lab

Experimental Android-native 2D graphics and pixel-processing engine using Google Skia, Rust, and GitHub Actions CI.

## Structure

- `app/`: Android application (Kotlin)
- `native/`: Rust native engine
- `docs/`: Research, architecture, dependencies, benchmarks
- `scripts/`: Helper scripts
- `/.github/workflows/`: CI/CD workflows
